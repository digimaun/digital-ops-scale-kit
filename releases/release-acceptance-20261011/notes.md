## Highlights

- Publication requires a passing acceptance run for the exact candidate:
  every installer cell, three single Site cases and a two Site fleet, each
  with its resources confirmed removed.
- Published releases must be immutable, so their tag and assets cannot change.
- The bootstrap discovers the source commit from verified provenance, so the
  short install command names only the release.
- Sites with names longer than 29 characters now install.
- This is a qualification prerelease for the maintainer fork.
