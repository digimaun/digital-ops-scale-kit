# Native Site Ops installation preview

This fork-only prerelease exercises publication of the native Site Ops
installation assets.

## Installation options

- Install the versioned Site Ops wheel with stock pipx and dependencies from
  your approved package index.
- Use the verified ZIP for the same engine wheel, pinned runtime wheels,
  producer-generated `pylock.toml`, and license notices.
- Inspect the independent provenance proof published for each asset.

The verified path uses pipx 1.17.2 and its shared pip 26.2.1 backend.
The pip lock reader remains experimental.

This is a publication rehearsal, not an official Scale Kit release. Installing
the CLI does not acquire workspace content or deploy Azure resources.
