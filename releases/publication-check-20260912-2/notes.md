## Highlights

This fork-only prerelease exercises the reviewed release headline and final
native Site Ops publication path.

- Install one identified engine wheel through stock pipx, or use the verified
  bundle with its recorded runtime dependencies.
- Review a descriptive release title and the exact assets before approving
  publication.
- Follow the first-site quickstart, then use the same manifest across a fleet.

The verified path uses pipx 1.17.2 and its shared pip 26.2.1 backend.
The pip lock reader remains experimental.

This is a publication rehearsal, not an official Scale Kit release. Installing
the CLI does not acquire workspace content or deploy Azure resources.
