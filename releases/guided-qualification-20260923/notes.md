## Highlights

Install Site Ops and acquire the IoT Operations workspace from this identified prerelease. The publisher is `digimaun/digital-ops-scale-kit`. Choose the HTTPS bootstrap when your policy accepts that delivery path, or authenticate the platform script's detached proof before running it. Both routes verify the engine bundle before installation.

Inspect `aio-install` inputs, provide an existing Arc-connected cluster resource ID, and authorize the resource read before planning a single Site. Secret Sync enablement is optional and checks the cluster's reported OIDC issuer and workload identity prerequisites before writes. Save separate ordinary Sites for a new fleet cohort and use an explicit name selector to review its targets before deployment.

## Upgrading

Commands now reject repeated single-file options and repeated project, source, trust, authentication, release, or parallel-cap selections instead of silently accepting the last value. Supply one value for each of those options. Repeat `--input` for distinct named answers and `-l` according to the documented selector rules.
